## 🚀 The Vision

Today’s algorithms optimize for attention. **Aura optimizes for human potential.** 

Individuals seeking personal growth often face a massive hurdle: finding the right resources, at the exact right moment, that align with their evolving identity. Aura is an agentic AI curator that deeply understands a user's aspirations, current emotional state, and habits to continuously curate the most relevant media, knowledge, and tools to help them become the self they imagine.

## ✨ Key Features

*   **🧠 Deep Context Engine:** Aura doesn't just recommend; she understands. By analyzing daily check-ins, mood, and long-term goals, Aura knows when to push you and when to offer a moment of reflection.
*   **🎯 Dynamic Curation:** Pulls high-signal content (articles, podcasts, tools, mentors) tailored to the user's exact micro-journey.
*   **⚡ Gen-Z Native UI:** A fluid, dark-mode, distraction-free interface designed to feel like a conversation with a hyper-intelligent mentor, not a traditional LMS.
*   **🔒 Secure & Persistent:** User identities, goals, and chat histories are securely stored, allowing Aura's understanding of the user to evolve over time.

## 🛠️ Tech Stack

We relied on a modern "vibe coding" stack to rapidly prototype and deploy this solution within 24 hours:

*   **Frontend:** Next.js (App Router), React, Tailwind CSS, shadcn/ui
*   **Backend & Database:** Next.js API Routes, Supabase (PostgreSQL)
*   **AI Engine:** Groq / OpenAI (for LLM inference & contextual understanding)
*   **Data Integration:** Tavily API (for real-time web curation)
*   **Deployment:** Vercel
